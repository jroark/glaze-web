Glaze vs Windows CE

How Glaze compares with the Windows CE 3.0 the Casio BE-300 shipped with, on the same machine: how long each takes to start, how much of the 16 MiB of RAM it leaves free, and how quickly it opens comparable apps.

Measured in the BE-300 emulator, both systems the same way, November 8, 2026. App launches were also measured on a real BE-300; see how it was measured.

How it was measured

  • Where: the be300 emulator (1731cc7), headless, at its default speed of 166 million instructions a second, close to the BE-300's VR4131 at 166 MHz. It doesn't model cache contents or flash timing exactly, so a real BE-300 will differ.
  • Glaze: Glaze OS 1.3 (source 81fc6d1), measured by tests/bench.py: a scripted unlock, then each app tapped on the home screen, opened again after Home. App times run from the tap to the app's first frame.
  • Windows CE: the BE-300's Windows CE 3.0 factory image, measured by tests/bench_ce.py with a small probe (wince/ce_bench) that Windows CE starts from a CompactFlash card. It starts each app and times it until the app's window is in front and its message loop answers. Free memory is GlobalMemoryStatus.
  • Runs: every number is the median of three cold boots from a fresh copy of each system's flash. Boot times are wall-clock seconds; everything else is the guest's own clock.
  • On the device: a real BE-300 over its USB sync cable. Windows CE ran the same probe from its flash disk; Glaze was started into RAM from Windows CE with GlazeBoot and given the same taps as in the emulator.
  • Not compared: waking from sleep, battery life, and start-up and memory on the device.

Details, commands and the raw results are in docs/os/PERFORMANCE.md.
